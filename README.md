\# CI/CD Pipeline Application



A simple Flask application used to demonstrate CI/CD, Docker, Jenkins, GitHub Actions, Docker Hub, and Kubernetes.



\## Technologies



\- Python

\- Flask

\- Docker

\- Jenkins

\- GitHub Actions

\- Docker Hub

\- Kubernetes



\## Project Features



\- Flask web application

\- Automated testing using pytest

\- Docker containerization

\- Docker Hub image management

\- Jenkins CI/CD pipeline

\- GitHub Actions workflow

\- Kubernetes deployment
